# Vibe Coding 빠른 시작

> 10분 만에 첫 웹 애플리케이션을 만들고 배포하기



안녕하세요, 저는 프로그래머 鱼皮입니다. 전 Tencent 풀스택 개발자이자, 전체 플랫폼 200만 팔로워를 보유한 [AI 프로그래밍 블로거](https://space.bilibili.com/12890453)이며, [AI 导航](https://ai.codefather.cn)와 [编程导航](https://www.codefather.cn) 등 10개 이상의 자체 개발 제품을 만든 창작자입니다.

지난 글에서는 Vibe Coding의 이념과 사고방식에 대해 이야기했습니다. 이제 직접 실습할 시간입니다!

이 글에서는 10분 안에 첫 번째 웹 애플리케이션을 만들고, 인터넷에 배포하여 전 세계 사람들이 접속할 수 있도록 하는 과정을 단계별로 안내하겠습니다.

네, 맞습니다. 프로그래밍 기초 지식이 전혀 필요 없습니다. 타이핑과 인터넷 사용만 할 수 있다면 따라 할 수 있습니다.



## 1. 준비 작업

시작하기 전에 간단한 준비가 필요합니다. 걱정하지 마세요. 매우 간단하며 5분이면 충분합니다.

필요한 것들:

1. 인터넷에 연결된 컴퓨터 (Windows, Mac 모두 가능)
2. 브라우저 (Chrome, Edge, Safari 모두 가능)
3. AI 도구 계정 (Bolt.new를 사용, 무료)
4. GitHub 계정 (배포용, 무료)

이것이 전부입니다. 프로그래밍 소프트웨어 설치도 필요 없고, 코드를 배울 필요도 없으며, 모든 것이 브라우저에서 완료됩니다.

💡 GitHub란?

[GitHub](https://github.com/)는 현재 가장 주류인 무료 코드 오픈소스 호스팅 플랫폼으로, 코드를 저장하고 관리하는 "클라우드 저장소"라고 이해할 수 있습니다. 모든 사용자나 팀은 자신의 코드를 GitHub에 업로드하여 공유하고 유지 관리할 수 있으며, GitHub에서 코드를 다운로드할 수 있습니다. 개발자들은 GitHub에서 무료로 코드를 받아 학습하거나 참조할 수 있습니다.

GitHub에 관심이 있다면 [鱼皮의 완벽 가이드 GitHub 학습 로드맵](https://www.codefather.cn/course/1789189862986850306/section/1789190804671012866)을 무료로 학습할 수 있습니다.



### AI 도구를 어떻게 선택할까?

완전 초보자에게는 Bolt.new로 시작할 것을 강력히 추천합니다. 완전히 온라인이며, 소프트웨어 설치가 필요 없고, 브라우저만 열면 사용할 수 있습니다. 가장 좋은 점은 코드를 작성하면 즉시 결과를 볼 수 있고, 완료 후 한 번의 클릭으로 온라인에 게시할 수 있어 진입 장벽이 전혀 없다는 것입니다. 무료 할당량도 있어 초보자가 연습하기에 충분합니다.

익숙해지면 Cursor와 같은 전문 도구를 배워도 늦지 않습니다.

참고로, 네트워크에서 Bolt.new에 접속할 수 없다면 [美团 NoCode](https://nocode.cn/) 또는 [百度秒哒](https://www.miaoda.cn/)를 시도해볼 수 있습니다. 모두 유사한 AI 애플리케이션 생성 플랫폼입니다.



### Bolt.new 등록

1) 브라우저를 열고 https://bolt.new 방문

2) 오른쪽 상단의 "Sign in" 버튼 클릭

3) Google 계정 / GitHub 계정 / 이메일 비밀번호로 로그인 선택 가능 (GitHub 추천, 나중에 배포할 때 사용)

로그인에 성공하면 준비 작업이 완료됩니다. 이제 대화 상자에 요구사항을 입력하여 프로젝트를 생성할 수 있습니다.

## 2. 첫 번째 프로젝트 선택

첫 번째 프로젝트는 매우 중요하며, 학습 경험을 직접적으로 결정합니다. 간단하지만 완전한 프로젝트를 선택하고, 실용적이며 결과를 볼 수 있는 것이 좋습니다.

제 경험상 다음 프로젝트들이 초보자에게 적합하며, 모두 쉽게 완성할 수 있습니다.

1) 개인 명함 웹페이지: 이름, 사진, 자기소개 및 연락처를 표시하는 간결하고 아름다운 페이지. 빠르게 성취감을 경험하고 싶은 분들에게 적합합니다.

2) 할 일 목록 애플리케이션: 간단한 작업 관리 도구(일명 Todo List)로, 작업 추가, 완료 표시, 작업 삭제 기능이 있습니다. 실용적인 도구를 만들고 싶은 분들에게 적합합니다.

3) 카운트다운 웹페이지: 목표 날짜(예: 시험, 생일)를 설정하고 남은 날짜를 실시간으로 표시하며 아름다운 시각 효과가 있습니다. 창의적인 것을 만들고 싶은 분들에게 적합합니다.

이 튜토리얼에서는 고전적인 **할 일 목록 애플리케이션**을 예로 들겠습니다. 기능이 완전하고 실용성이 강하며, 전체 개발 프로세스를 경험할 수 있기 때문입니다. 다른 프로젝트를 만들고 싶다면 전혀 문제없습니다. 단계는 동일하며 요구사항 설명만 원하는 것으로 바꾸면 됩니다.



## 3. AI와 대화하여 코드 생성

자, 이제 가장 흥미진진한 부분을 시작합니다 — AI와 대화하여 코드를 생성하도록 합니다.


### 1라운드 대화: 기본 요구사항 설명

Bolt.new 채팅창에 다음 내용을 입력합니다(직접 복사할 수 있습니다):

```
할 일 목록 애플리케이션 웹페이지를 만들어주세요. 요구사항:

1. 기능 요구사항:
   - 작업 내용을 입력하고 목록에 추가할 수 있음
   - 각 작업 앞에 체크박스가 있어 클릭하면 완료로 표시됨
   - 완료된 작업은 취소선으로 표시됨
   - 각 작업 뒤에 삭제 버튼이 있음
   - 완료된 작업과 미완료 작업의 수량 표시

2. 인터페이스 요구사항:
   - 간결하고 현대적인 디자인 스타일
   - 신선한 파란색 톤 사용
   - 둥근 모서리 버튼과 입력 상자
   - 적절한 그림자 효과
   - 반응형 디자인, 모바일에서도 정상적으로 사용 가능

3. 기술 요구사항:
   - HTML + CSS + JavaScript 사용
   - 데이터는 브라우저 로컬 스토리지에 저장, 페이지 새로고침 시 손실되지 않음
```

대형 모델 선택, 계획 모드 사용, 첨부파일 추가, 프롬프트 강화 등을 선택할 수도 있지만, 처음에는 이런 것들에 신경 쓰지 말고 바로 전송을 클릭하고 AI의 응답을 기다리는 것을 권장합니다.

### AI는 무엇을 하고 있나요?

전송 후 Bolt.new가 작업을 시작하는 것을 볼 수 있습니다.

AI가 요구사항을 이해한 후 프로젝트 파일 구조를 생성하고, 웹페이지 코드를 자동으로 생성합니다. 전체 프로세스는 약 2분이 소요됩니다.

코드 생성이 완료되면 오른쪽에 미리보기 효과가 자동으로 표시됩니다. 입력 상자, 추가 버튼, 작업 목록 영역을 볼 수 있습니다.

입력 상자에 "鱼皮와 함께 Vibe Coding 배우기"를 입력하고 추가 버튼을 클릭하여 결과를 확인해보세요.

### 2라운드 대화: 세부사항 최적화

초기 버전의 결과를 본 후 일부 세부 사항을 조정하고 싶을 수 있습니다. 예를 들어:

```
좋습니다! 하지만 몇 가지 조정을 하고 싶습니다:

1. 입력 상자의 플레이스홀더 텍스트를 "오늘 무엇을 할까요?"로 변경
2. 추가 버튼을 "➕ 작업 추가"로 변경
3. 제목을 "나의 할 일 목록"으로 변경하고 귀여운 아이콘 추가
4. 배경색을 연한 파란색에서 연한 보라색으로의 그라디언트로 변경
5. "완료된 항목 지우기" 버튼 추가
```

시각적 수정 기능을 켜서 수정하고 싶은 요소를 선택할 수도 있습니다. 마음에 들지 않는 곳을 클릭하세요~

![](https://pic.yupi.icu/1/image-20260104141819294.png)

AI가 요청에 따라 코드를 수정하며, 곧 새로운 효과를 볼 수 있습니다.

![](https://pic.yupi.icu/1/image-20260104142026165.png)




### 3라운드 대화: 새로운 기능 추가

더 많은 기능을 추가하고 싶다면 AI와 계속 대화하세요:

```
몇 가지 기능을 더 추가해주세요:

1. 작업에 우선순위(높음, 중간, 낮음)를 설정할 수 있고, 다른 색상으로 표시
2. 이미 추가된 작업을 편집할 수 있음
3. "모두 지우기" 버튼을 추가하고 확인 필요
4. 작업 목록이 비어있을 때 친근한 메시지 표시
```

AI가 계속해서 이러한 기능을 구현해줄 것입니다.

### 대화 팁

AI와 대화할 때 다음 사항을 기억하세요:

1. 요구사항은 구체적으로: "더 예쁘게 만들어주세요"가 아니라 "배경을 파란색 그라디언트로 변경하고 버튼에 둥근 모서리 추가"라고 말하세요
2. 한 번에 너무 많이 변경하지 마세요: 매번 1~5개의 요청만 하고, 수정 후 결과를 보고 계속하세요
3. 문제가 있으면 바로 말하세요: 버그가 있거나 효과가 맞지 않으면 AI에게 "XX 여기에 문제가 있습니다"라고 직접 알려주세요
4. 설명을 요청할 수 있습니다: 이해가 안 되는 부분은 "이 코드는 무엇을 하나요?"라고 물어보세요



## 4. 효과 검증

이제 할 일 목록 애플리케이션이 완성되었습니다. 각 기능을 테스트해봅시다:

1) 입력 상자에 "鱼皮와 함께 Vibe Coding 배우기"를 입력하고 추가 버튼을 클릭하면 작업이 목록에 나타납니다

2) 작업 앞의 체크박스를 클릭하면 작업 텍스트에 취소선이 표시되고, 삭제 버튼을 클릭하면 작업이 목록에서 사라집니다.

마지막으로 미리보기 창 상단의 장치 아이콘을 클릭하여 모바일 및 다양한 화면에서의 효과를 확인하세요.

![](https://pic.yupi.icu/1/image-20260104142538383.png)

특정 기능이 정상적으로 작동하지 않으면 당황하지 마세요. AI에게 문제를 자세히 설명하세요. 예를 들어 "삭제 버튼을 클릭한 후 작업이 삭제되지 않았습니다"라고 하면 AI가 버그를 수정해주고, 그 후 다시 테스트하면 됩니다.

이것이 Vibe Coding의 매력입니다 — 문제가 생기면 AI가 해결해줍니다!

## 6. 만든 것 이해하기

프로젝트를 완료했으니 몇 분 동안 만든 것을 이해해봅시다. 이렇게 하면 나중에 더 나은 프로젝트를 만드는 데 도움이 됩니다.




### 프로젝트 구조

먼저, 웹 애플리케이션의 기초는 "프론트엔드 3종 세트"라는 것을 알아야 합니다:

- HTML (구조): 페이지에 어떤 요소가 있는지 정의합니다. 예: 입력 상자, 버튼, 작업 목록, 통계 정보.
- CSS (스타일): 페이지가 어떻게 보이는지 정의합니다. 색상, 글꼴, 크기, 레이아웃 및 간격, 애니메이션 효과 포함.
- JavaScript (기능): 페이지가 어떻게 작동하는지 정의합니다. 작업 추가, 완료 표시, 작업 삭제, 로컬 스토리지 로직 포함.

하지만 이 프로젝트에서 AI는 **React**라는 현대적인 프론트엔드 개발 프레임워크를 사용하여 기능을 구현하기로 선택했습니다. React는 현재 가장 인기 있는 프론트엔드 프레임워크 중 하나로, 개발을 더 효율적으로 만들고 코드를 유지 관리하기 쉽게 만듭니다.

따라서 프로젝트 파일에서 `.tsx` 확장자를 가진 파일을 볼 수 있는데, 이것들이 React 컴포넌트 파일입니다. 하지만 본질적으로 이들은 최종적으로 브라우저가 이해할 수 있는 HTML, CSS 및 JavaScript로 변환됩니다.

![](https://pic.yupi.icu/1/image-20260104162356144.png)

괜찮습니다. 지금 이해하지 못해도 전혀 문제없습니다. 프론트엔드 개발에 관심이 있는 학생은 [鱼皮의 최신 완벽 가이드 프론트엔드 학습 로드맵](https://www.codefather.cn/course/1789189862986850306/section/1789190394078011393)을 보고 빠르게 시작할 수 있습니다.




### 핵심 기능 분석 (건너뛸 수 있음)

몇 가지 핵심 기능이 어떻게 구현되는지 살펴봅시다:

1) 작업 추가: "작업 추가" 버튼을 클릭하면 프로그램이 먼저 입력 상자의 텍스트를 가져온 다음 새 작업 객체를 생성하고, 작업을 목록에 추가하며, 동시에 로컬 스토리지에 저장하고, 마지막으로 입력 상자를 지우고 페이지 표시를 새로 고칩니다. 전체 프로세스는 종이에 할 일 항목을 적은 다음 벽에 붙이는 것만큼 자연스럽습니다.

2) 완료 표시: 체크박스를 클릭하면 프로그램이 해당 작업을 찾고, 완료 상태를 수정하고, 로컬 스토리지를 업데이트한 다음 페이지 표시를 업데이트합니다(작업 텍스트에 취소선 추가). 동시에 통계 숫자를 업데이트합니다. 종이의 작업에 펜으로 줄을 긋는 것과 같습니다.

3) 로컬 스토리지

페이지를 새로 고쳐도 작업이 남아있는 이유가 궁금할 수 있습니다.

이는 데이터가 브라우저의 로컬 스토리지(localStorage)에 저장되기 때문입니다. 작업을 수정할 때마다 프로그램은 최신 데이터를 localStorage에 저장합니다. 페이지를 다시 열면 프로그램이 localStorage에서 이전에 저장한 데이터를 읽습니다. 이렇게 하면 브라우저를 닫아도 데이터가 손실되지 않습니다. 할 일 목록을 잃어버리지 않는 작은 노트에 적는 것과 같습니다.

![](https://pic.yupi.icu/1/theoryofworksoftware%E5%A4%A7.jpeg)



### AI에게 배우기

특정 부분을 깊이 이해하고 싶다면 AI에게 직접 물어볼 수 있습니다:

```
로컬 스토리지가 어떻게 작동하는지 설명해주세요.
```

또는:

```
이 코드는 무엇을 하나요?
[코드 붙여넣기]
```

AI가 쉽게 이해할 수 있는 언어로 설명해줄 것입니다.



## 7. 수정 및 최적화 시도

이제 실용적인 작은 소프트웨어를 갖게 되었으니, 수정과 최적화를 시도하여 이해를 깊게 해봅시다.

시도해볼 수 있는 것들:

- 색상 테마 변경 ("애플리케이션을 핑크 테마로 변경, 부드럽고 귀여운 느낌")
- 텍스트 수정 ("모든 텍스트를 영문 버전으로 변경")
- 레이아웃 조정 ("통계 정보를 페이지 하단으로 이동하고 가운데 정렬")

또는 새로운 기능 추가:

- 작업 검색 ("검색 상자를 추가하여 작업 내용을 검색할 수 있게")
- 작업 분류 ("분류 기능을 추가하여 작업에 태그를 추가할 수 있게")
- 내보내기 기능 ("버튼을 추가하여 모든 작업을 텍스트 파일로 내보낼 수 있게")

사용자 경험을 최적화하여 애플리케이션을 더 좋게 만들 수도 있습니다:

- 단축키 추가 ("Enter 키를 눌러 빠르게 작업 추가")
- 애니메이션 추가 ("작업 추가 시 페이드인 애니메이션, 작업 삭제 시 슬라이드아웃 애니메이션")
- 빈 상태 최적화 ("작업이 없을 때 귀여운 일러스트와 격려 문구 표시")

간단하다고 생각되면 다음을 추가해볼 수 있습니다:

- 마감일 기능
- 작업 알림 기능
- 드래그 앤 드롭 정렬 지원
- 다크 모드 전환 추가
- 여러 작업 목록 지원

새 기능을 추가하고 싶을 때마다 AI에게 "저는 [기능 설명]을 추가하고 싶습니다. 어떻게 해야 하나요?"라고 말하면 AI가 구현해줄 것입니다.

첫 번째 글에서 말한 것을 기억하세요: **AI 시대에는 창의력이 기술보다 중요하고, 아이디어가 구현보다 중요하며, 반복이 완벽보다 중요합니다.**
