# AI 모델 선택 가이드

안녕하세요, 저는 물고기皮입니다.

우리는 이미 AI 프로그래밍 도구의 3가지 주요 유형을 알아보았습니다. 하지만 여러분이 제로코드 플랫폼, 코드 에디터, 명령줄 도구 중 무엇을 선택하든, 그 뒤에는 공통적인 핵심이 있습니다 —— **AI 모델**.

여러분은 아마 이런 궁금증이 있을 것입니다:

- Cursor에서 Claude, ChatGPT, Gemini를 선택할 수 있는데, 이들은 도대체 무슨 차이가 있나요?
- 왜 어떤 사람은 Claude 프로그래밍이 최강이라고 하고, 어떤 사람은 ChatGPT를 더 추천하나요?
- 국산 대형 모델은 믿을 만한가요? 해외 모델과의 격차는 얼마나 되나요?

걱정하지 마세요. 이 글에서 저는 가장 이해하기 쉬운 방식으로, 주류 AI 모델의 특징을 알려드리고, 자신의 니즈에 맞는 모델을 선택하는 방법을 알려드리겠습니다.

참고로, AI 모델은 업데이트가 매우 빠르기 때문에, 이 글의 내용은 2026년 1월 상황을 기준으로 합니다. 앞으로 새로운 모델이 등장하거나 기존 모델의 능력이 변할 수 있습니다. 따라서 최신 동향을 계속 주시하고, 자신의 선택을 유연하게 조정해야 합니다.



## 1. AI 모델이란 무엇인가요?

먼저 기본 개념부터 확실히 짚고 넘어가겠습니다: AI 모델이란 무엇일까요?

간단히 말해서, **AI 모델은 Vibe Coding 도구 뒤에 있는 "두뇌"입니다**.

AI 프로그래밍 도구에 요구사항을 입력할 때, AI 모델이 여러분의 말을 이해하고 있습니다. 생성된 코드를 볼 때도, AI 모델이 작성한 것입니다. 서로 다른 AI 모델은 마치 서로 다른 분야의 전문가처럼 각각의 장점이 있습니다. 어떤 것은 코드 작성에 능하고, 어떤 것은 문헌 정리에 능하며, 어떤 것은 속도가 빠르고, 어떤 것은 품질이 높습니다.

비유하자면:

- AI 프로그래밍 도구(Cursor, Bolt.new) = 작업대
- AI 모델(Claude, ChatGPT) = 작업대 앞에 앉아서 일하는 프로그래머

따라서, 똑같이 Cursor를 사용하더라도 Claude를 선택하는 것과 ChatGPT를 선택하는 것은 마치 2명의 다른 스타일의 프로그래머를 고용해서 코드를 작성하는 것과 같아서, 최종 결과가 당연히 다를 수밖에 없습니다.

## 2. 주류 AI 모델

2026년 1월 기준, 시장의 AI 모델은 이미 매우 풍부해졌습니다. 출처와 포지셔닝에 따라 3대 진영으로 나눌 수 있습니다:

- 국제 최고급 모델: Claude, ChatGPT, Gemini 3대 거물
- 국산 우수 모델: DeepSeek, 智谱 GLM, 通义千问, Kimi 등 가성비 선택
- 그리고 오픈소스 모델: Llama, Qwen 등, 일정한 기술 능력이 필요하며 직접 배포

Vibe Coding 학습에 있어서는 앞의 두 가지 유형에 주목하면 충분합니다. 오픈소스 모델은 유연하지만, 설정과 사용 진입장벽이 높아 초보자에게는 적합하지 않습니다.

![](https://pic.yupi.icu/1/image-20260106202328517.png)

다음으로, 이러한 주류 모델의 특징을 하나씩 소개하여 자신에게 가장 적합한 모델을 찾을 수 있도록 도와드리겠습니다.



## 3. Claude - 최강 코딩 능력

Claude 4.5는 Anthropic 회사가 2025년에 출시한 최신 버전으로, 2026년 1월 현재까지도 프로그래밍 능력이 가장 강력한 AI 모델로 인정받고 있습니다.

Claude 4.5는 주로 두 가지 버전이 있습니다: Opus 4.5는 최고급 버전으로 프로그래밍 능력이 가장 강하지만 속도가 상대적으로 느리고 가격도 더 비쌉니다. Sonnet 4.5는 균형 잡힌 버전으로 성능과 속도 사이에서 좋은 균형을 이루어 가성비가 가장 높습니다.



### 왜 Claude 프로그래밍이 최강일까?

권위 있는 SWE-bench(소프트웨어 엔지니어링 벤치마크 테스트)에서 Claude Opus 4.5의 점수는 GPT-5와 Gemini 3 Pro를 초과하여 프로그래밍 분야 SOTA(최첨단 수준)의 왕좌를 굳건히 지키고 있습니다. 구체적으로 Claude는 코드 이해, 리팩토링, 디버깅 등의 측면에서 모두 특히 뛰어납니다. 복잡한 코드 로직을 정확하게 이해할 수 있고, 기존 코드를 최적화하고 개선하는 데 능하며, 빠르게 버그를 찾아 수정할 수 있고, 또한 컨텍스트 기억력이 좋아 쉽게 망각하지 않습니다.

이러한 장점은 Claude를 고품질 코드가 필요한 개발자, 복잡한 프로젝트를 하는 사람, 코드 품질 요구가 높은 시나리오에 특히 적합하게 만듭니다.

**물론, 전제는 예산이 충분해야 합니다.**




### 가격 및 획득 방법

Claude는 주로 3가지 사용 방식이 있습니다:

- 공식 구독: Claude Pro 월 20달러 (약 145위안)
- Cursor를 통해: Cursor Pro 구독 월 20달러, Claude 사용 할당량 포함
- API 호출: Token 기준 과금, 사용한 만큼 지불, 비교적 유연함

![Claude 공식 가격](https://pic.yupi.icu/1/image-20260106203330977.png)

만약 Vibe Coding을 진지하게 배우고 싶고, 상업급 제품을 직접 만들고 싶다면 Cursor Pro 구독을 추천합니다. 똑같이 20달러로 Claude뿐만 아니라 다른 모델로도 전환 가능하여 가성비가 가장 높습니다.

다만 주의할 점은 Cursor 패키지는 무제한이 아니며, 초과하면 추가 비용이 발생합니다. 제 청구서를 보여드리겠습니다:

![](https://pic.yupi.icu/1/image-20260106202855849.png)

또한 학습 리소스 [Claude Cookbooks](https://github.com/anthropics/claude-cookbooks)를 추천합니다. Anthropic 공식에서 제공하는 Claude 사용 팁과 코드 예제 모음으로, 도구 호출, RAG, 분류, 요약, 멀티모달 등 다양한 실용 시나리오의 튜토리얼이 포함되어 있어 학습할 가치가 매우 높습니다.



## 4. ChatGPT - 지능과 속도를 겸비

Claude를 얘기했으니, 이제 ChatGPT를 살펴보겠습니다.

ChatGPT는 OpenAI 회사의 제품으로, AI 채팅을 전 세계적으로 유행시킨 최초의 도구입니다. 2025년에 OpenAI는 GPT-5 시리즈를 출시했는데, 범용 버전인 GPT-5, 추론 능력이 더 강한 GPT-5 Pro, 그리고 논리, 수학, 프로그래밍에 특화 최적화된 o3 버전이 포함됩니다.

![](https://pic.yupi.icu/1/image-20260106221446611.png)

비록 순수 프로그래밍 능력 비교에서는 ChatGPT가 Claude에 약간 뒤지지만, 자신만의 독특한 장점이 있습니다.

첫째는 속도가 더 빠릅니다. 코드 생성 속도가 Claude보다 상당히 빨라 빠른 반복이 필요한 시나리오에 특히 적합합니다. 둘째는 지식 업데이트가 신속합니다. 최신 기술과 프레임워크에 대한 이해가 더 빠릅니다. 또한 생태계가 더 좋고, 플러그인과 도구 지원이 더 풍부하며, 중국어 이해 및 생성 능력도 더 강합니다.

따라서 빠른 프로토타입 개발이 필요하거나, 속도 요구가 높거나, 다양한 플러그인과 도구를 사용해야 한다면 ChatGPT도 좋은 선택입니다.

ChatGPT의 가격 및 획득 방법:

- ChatGPT Plus: 월 20달러
- ChatGPT Pro: 월 200달러 (o3 등 고급 모델 포함)
- API 호출: Token 기준 과금

![](https://pic.yupi.icu/1/image-20260106203501181.png)



## 5. Gemini 3.0 - 초장 컨텍스트의 왕

다음은 Gemini입니다. Google이 출시한 AI 모델입니다. 2025년의 Gemini 3.0 시리즈는 주로 두 가지 버전이 있습니다: 최고급 Gemini 3 Pro는 각 방면의 능력이 매우 종합적이고, 경량급 Gemini 3 Flash는 속도가 극도로 빠르며 가격도 저렴합니다.

![](https://pic.yupi.icu/1/image-20260106221514964.png)

Gemini의 가장 강력한 점은 초장 컨텍스트 창입니다. Gemini 3 Pro는 **1M Token**(약 100만 자)의 입력 컨텍스트를 지원합니다.

이것이 무엇을 의미할까요?

대형 프로젝트의 모든 코드를 한 번에 읽을 수 있고, 초장 대화 기록을 기억하여 쉽게 망각하지 않으며, 대량의 문서와 자료를 동시에 분석할 수 있습니다.

그리고 UI 구축 측면에서도 Gemini 3 Pro의 표현이 특히 뛰어납니다. 실측에 따르면 프론트엔드 UI 디자인, 3D 모델 구축 등의 측면에서 능력이 강력하며, 일부 시나리오에서는 Claude와 GPT-5를 능가하기도 합니다.

![한마디로 3D 애니메이션 웹사이트 개발](https://pic.yupi.icu/1/1763785739331-b643bd7d-85d6-42d9-8462-f842a8a790e6.png)

따라서 대형 프로젝트를 처리해야 하거나, 대량의 코드를 분석해야 하거나, UI/프론트엔드 개발을 하거나, 예산이 제한적이지만 강력한 능력이 필요하다면 Gemini가 좋은 선택이 될 것입니다.

Gemini의 가격 및 획득 방법:

- Gemini 3 Pro: 월 19.99달러
- API 호출: Claude와 GPT보다 가격이 훨씬 저렴
- 무료 버전: Gemini 3 Flash는 일정한 무료 할당량이 있고, 매일 몇 번의 사고 모델 시험 사용 가능



## 6. 국산 대형 모델 - 가성비의 선택

### 주류 국산 모델은 어떤 것들이 있나요?

국제 3대 거물을 얘기했으니, 이제 국산 대형 모델을 살펴보겠습니다. 현재 국산 대형 모델은 프로그래밍 능력에서 이미 따라잡았고, 일부 측면에서는 국제 모델을 초월하기도 합니다!

- DeepSeek-V3는 오픈소스 모델로 완전 무료 사용이며, 프로그래밍 능력이 국산 모델 중 1, 2위를 다투고, API 가격이 극도로 낮아 대량 호출이 필요한 시나리오에 특히 적합합니다.
- Alibaba 通义千问 Qwen은 LiveCodeBench 평가에서 GPT-5를 능가하는 성능을 보였고, 중국어 이해 능력이 극도로 강하여 중국어로 요구사항을 제시하면 특히 정확합니다.
- 智谱 GLM-4.7은 칭화대학 팀이 만든 것으로, 다국어 프로그래밍 능력이 강하고 중국어 개발 시나리오에 특화 최적화되었습니다. 200K Token의 긴 컨텍스트를 지원하며, 복잡한 작업 실행과 창의적 작문 측면에서 좋은 성능을 보입니다. 저도 계속 GLM을 사용하여 개발하고 있으며, 완전한 프로젝트 생성 측면에서 속도와 효과 모두 매우 좋습니다.
- 月之暗面 Kimi는 매우 일찍부터 초장 컨텍스트 능력(200만 자)을 지원하여 국산 모델 중 독보적입니다. 대형 프로젝트 코드 처리에 특히 적합하며, 한 번에 500개 파일을 처리할 수 있습니다.
- Tencent 混元 CodeBuddy는 Tencent Cloud 서비스와 깊이 통합되며, 네이티브로 3000+ 클라우드 API에 연동되고, 등급보호 3급 보안 인증을 받아 기업 사용에 적합하며 가격도 저렴합니다.
- Baidu 文心一言은 무료 할당량이 있고, Baidu 생태계(예: Baidu 秒哒 플랫폼)와 깊이 통합되어 창의적인 소규모 프로젝트가 빠른 상업화가 필요한 시나리오에 적합합니다.



### 국산 모델의 장점과 한계

국산 모델의 가장 큰 장점은 가격이 저렴하다는 것입니다. API 가격이 일반적으로 국제 모델의 1/10입니다. 또한 중국어 이해가 더 정확하고, 국내 직접 접속 속도가 빠르며, 국내 법규 요구사항을 충족합니다.

물론 일부 한계도 있습니다. 가장 복잡한 작업에서는 최고 능력이 여전히 Claude Opus 4.5보다 약간 못하고, 도구와 플러그인 지원도 국제 모델만큼 풍부하지 않습니다.

다만 예산이 제한적인 학생과 개인 개발자, 주로 중국어 프로젝트를 하는 사용자, 국제 서비스 접근이 불편한 사용자, 또는 대량의 API 호출이 필요한 시나리오에서는 국산 모델이 매우 좋은 선택입니다. 제 많은 AI 제품이 DeepSeek, 通义千问 또는 GLM에 연동되어 있으며, 그들이 제공하는 무료 할당량만으로도 일상 학습 사용에 충분합니다.

그리고 저는 국산 모델이 국제 모델을 초월할 기회가 있다고 믿으며, 오픈소스의 힘을 믿습니다!

## 7. 적합한 모델을 선택하는 방법은?

이렇게 많은 모델이 있고 각각의 장점이 있는데, 도대체 어떤 것을 선택해야 할까요?

사실 모델 선택은 주로 두 가지 차원을 봅니다: 예산과 사용 시나리오입니다.



### 예산에 따른 선택

예산의 많고 적음이 어떤 도구를 사용할 수 있는지 직접적으로 결정합니다.

예산이 충분하다면(월 100위안 이상), Cursor Pro(20달러)를 구독하여 Claude Opus 4.5 또는 Sonnet 4.5와 함께 사용할 수 있습니다. 이것이 현재 경험이 비교적 좋은 조합입니다. Claude의 코드 품질이 높아 복잡한 프로젝트와 상업 프로젝트에 특히 적합합니다.

예산이 제한적이라면 무료 리소스를 충분히 활용하세요. DeepSeek 완전 무료 + 通义千问 무료 할당량 + Gemini 3 Flash 매일 무료 할당량, 이러한 무료 리소스를 조합하면 학습과 개인 프로젝트에 완전히 충분합니다. 게다가 국산 모델의 API 가격이 매우 저렴하여, 유료라 해도 월 수십 위안으로 매우 즐겁게 사용할 수 있습니다.



### 시나리오에 따른 선택

서로 다른 개발 시나리오에는 적합한 모델도 다릅니다.

1) 학습 단계: 아직 학습 중이라면 주력으로 무료 DeepSeek 또는 通义千问을 사용하고, 보조로 Gemini 3 Flash의 무료 할당량을 사용하세요. 이 단계의 중점은 AI 프로그래밍의 감을 익히는 것이며, 무료 모델로 완전히 충분합니다.

2) 프론트엔드/UI 프로젝트: Gemini 3 Pro는 프론트엔드 UI 디자인 측면에서 특히 뛰어납니다. 실측 결과 질감이 좋은 인터페이스를 생성할 수 있고, 3D 모델 구축 능력도 강합니다. 주로 프론트엔드를 한다면 Gemini가 좋은 선택입니다.

3) 풀스택 프로젝트: 프로그래밍 능력이 강한 Claude Sonnet을 우선 선택하세요. 능력이 종합적이고 프론트엔드와 백엔드 모두 대응할 수 있습니다. Cursor와 함께 사용하면 개발 경험이 매우 좋습니다. 빠르게 완전한 프로젝트를 생성해야 한다면 智谱 GLM-4.7의 속도와 효과도 좋습니다.

4) 대형 코드베이스 처리: Gemini 3 Pro(1M Token)의 초장 컨텍스트 능력이 가장 적합하며, 한 번에 전체 프로젝트를 분석할 수 있습니다. 智谱 GLM-4.7은 200K Token을 지원하여 완전한 프론트엔드와 백엔드를 포함하는 중대형 프로젝트 코드도 처리할 수 있습니다.

5) 빠른 반복 개발: GPT-5의 응답 속도가 가장 빠르며, 빠른 아이디어 검증이 필요한 시나리오에 특히 적합합니다. 智谱 GLM도 생성 속도 측면에서 장점이 있습니다.

6) 대량 테스트 및 호출: DeepSeek은 완전 무료이며, DeepSeek와 通义千问의 API 가격이 극도로 낮아 대량 호출이 필요한 시나리오에 적합하고, 테스트 시 안심하고 사용할 수 있습니다.



### 개인적인 선택

저 개인적으로는 비교적 풍부한 프로젝트 개발 경험이 있고 많은 상업 프로젝트를 해봤기 때문에, 모델을 선택할 때 일반적으로 능력이 강한 대형 모델을 우선 고려합니다. 일상 개발은 주력으로 Cursor + Claude Sonnet을 사용하는데, 이 조합은 기능이 종합적이고 효과가 좋습니다.

기타 상황:

- 특별히 복잡한 문제를 만나면 Claude Opus로 전환합니다.

- 속도가 필요할 때는 智谱 GLM을 선택하는데, 빠른 완전 프로젝트 생성 측면에서 성능이 좋습니다.
- 대량 테스트 시에는 DeepSeek 또는 通义千问 API를 사용합니다. 상대적으로 저렴하기 때문입니다.
