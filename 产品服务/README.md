## 회사 소개

鱼鸢网络는 신흥 인터넷 과학기술 회사로, 저희의 사명과 비전은 "기술로 여러분의 매 순간을 절약합니다" 입니다.

저희는 과학기술 혁신을 통해 여러분의 학습, 업무, 생활 및 정보 획득의 효율성을 향상시켜, 더 나은 미래를 맞이하고자 합니다.
