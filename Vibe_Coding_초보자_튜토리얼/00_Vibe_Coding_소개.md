## 1. Vibe Coding이란 무엇인가요?

한 문장으로 Vibe Coding을 설명하자면, **자연어(사람의 말)로 AI와 대화하며, AI가 코드를 생성하고, 수정하고, 최적화하도록 하는 프로그래밍 방식**입니다.

여러분은 이렇게 말할 수도 있습니다: "그냥 AI로 코드 짜는 거 아니에요?"

틀린 말은 아니지만, 진정한 Vibe Coding은 단순히 AI에게 코드 몇 줄 짜달라고 하는 것보다 훨씬 더 큰 개념입니다. 이는 완전히 새로운 개발 사고방식이자 워크플로입니다.

좀 더 공식적인 언어로 표현하자면, Vibe Coding은 다음과 같습니다:

> 자연어 프롬프트로 대형 언어 모델(LLM)을 구동하여, AI가 직접 코드를 생성하고 반복 개선하는 의도 주도형 개발 모델.



이 모델에서는:

- 여러분은 "무엇을 할지 명확히 생각하는 것"(의도 표현)을 담당하고
- AI는 "그것을 만들어 내는 것"(논리 구현)을 담당하며
- 여러분은 함께 반복하고 최적화(협업 진화)합니다.

이렇게 복잡한 정의를 외울 필요는 없습니다. 다음만 기억하세요:

**Vibe Coding = 사람의 말로 AI와 대화 + AI가 코드 작성 + 함께 반복 최적화**

![](https://pic.yupi.icu/1/whatisvibecoding%E5%A4%A7.jpeg)



### 왜 "Vibe" Coding이라고 부를까요?

"Vibe"라는 단어는 원래 분위기, 느낌을 뜻합니다.

프로그래밍 영역에서 이는 특별한 의미를 갖습니다: **여러분이 원하는 "느낌"을 AI에게 말하기만 하면, AI가 여러분 머릿속의 아이디어를 실제 프로그램으로 바꿔준다는 것입니다.**

예를 들어:
- "깔끔하고 현대적인 가계부 페이지를 원해"라고 하면, AI가 깨끗하고 예쁜 인터페이스를 생성해 줍니다.
- "이 버튼을 클릭했을 때 애니메이션 효과가 있었으면 좋겠어"라고 하면, AI가 애니메이션을 추가해 줍니다.
- "이 페이지를 다크 모드로 바꿔줘"라고 하면, AI가 배색을 다시 설계해 줍니다.

정말 신기하지 않나요?

이것이 바로 Vibe Coding의 매력입니다. 프로그래밍을 마치 대화하듯 자연스럽게 만들어 줍니다.

**그럼 왜 분위기 프로그래밍이라고 할까요?**

제 이해를 말씀드리겠습니다.

Vibe Coding으로 개발할 때는 전체적인 작업 분위기가 완전히 달라집니다. 예전에 프로그래머가 코드를 짤 때는 키보드를 두드리며 인상을 쓰고, 버그가 생기면 인터넷에서 한참을 검색해야 했습니다. 하지만 지금은 기본적으로 에디터를 응시하며 몇 분마다 한 번씩 타이핑하고(AI와 대화), 표정은 여유로우며, 가끔은 갑자기 흥분하기도 합니다!

개발자의 작업 분위기뿐만 아니라 사무실 전체의 분위기도 달라졌습니다. 개발자가 문제를 논의할 때 기획자, 운영자 동료들도 와서 훈수를 둘 수 있습니다. 누구나 AI로 아이디어를 빠르게 검증할 수 있기 때문입니다.

**분위기 프로그래밍, 정말 맞는 말입니다.**



## 2. 핵심 이념: 의도 주도 프로그래밍

의도 주도란 무엇일까요?

전통적인 프로그래밍에서는 컴퓨터에게 "어떻게 할지"(How)를 알려주기 위해 직접 코드를 작성해야 했습니다:

```python
# 전통적인 방식: 각 단계를 어떻게 할지 작성해야 함
total = 0
for item in shopping_cart:
    total = total + item.price
print(total)
```

하지만 Vibe Coding에서는 AI에게 "무엇을 할지"(What)만 알려주면 됩니다:

```
나: 장바구니에 있는 모든 상품의 총액을 계산해 줘
AI: 알겠습니다, 이 기능을 구현하겠습니다
```

차이점이 보이시나요? 반복문을 어떻게 쓸지, 변수 이름을 어떻게 지을지 신경 쓸 필요 없이, 의도를 명확히 표현하기만 하면 AI가 구현해 줍니다.

Vibe Coding 시대에 가장 중요한 "프로그래밍 언어"는 Python이나 JavaScript가 아니라, **바로 여러분의 모국어**입니다!

이것이야말로 진정한 모국어 프로그래밍이죠. 제가 예전에 접했던 무슨 '이지 언어(易语言)', 'Q 언어' 같은 건 상대도 안 됩니다~

예전에 프로그래밍을 배울 때는 다음을 기억해야 했습니다:
- 변수 정의 방법
- 반복문 작성법
- 함수 호출법
- 각종 문법 규칙

이제는 사람의 말만 할 줄 알면 됩니다:
- "할 일 목록을 만들고 싶어"
- "이 버튼을 누르면 홈페이지로 이동해"
- "사용자가 잘못 입력하면 빨간색 경고를 보여줘"

**여러분의 의도가 곧 코드 로직입니다.**



### AI는 여러분의 프로그래밍 파트너

많은 사람들이 AI를 도구로만 사용하지만, Vibe Coding에서 AI는 도구가 아니라 프로그래밍 파트너입니다:

- 여러분은 제품 관리자(PM): 무엇을 할지 명확히 생각하는 역할
- AI는 엔지니어: 그것을 구현해 내는 역할
- 여러분은 팀: 함께 토론하고, 반복하고, 최적화함

이런 협업 모드는 프로그래밍을 "고독한 전투"에서 "즐거운 대화"로 바꿔줍니다.



## 3. 전통적 프로그래밍 사고방식 vs Vibe Coding 사고방식

표를 통해 두 가지 사고방식의 차이를 이해해 봅시다:

| 차원 | 전통적 프로그래밍 | Vibe Coding |
|------|----------|-------------|
| **핵심 능력** | 코드 작성 (문법 암기) | 요구 사항 표현 (사람 말하기) |
| **학습 중점** | 프로그래밍 언어, 알고리즘, 자료구조 | 제품 사고력, 요구 사항 표현, 반복 최적화 |
| **작업 방식** | 스스로 0부터 작성 | AI와 대화하여 생성 |
| **문제 발생 시** | 스스로 디버깅, 문서 조회, 검색 | 오류를 AI에게 말하고 고치게 함 |
| **코드 최적화** | 리팩토링, 알고리즘 최적화 | AI에게 최적화 방향 제시 |
| **학습 곡선** | 가파름 (수개월에서 수년 필요) | 완만함 (며칠이면 시작 가능) |
| **적합한 대상** | 이공계 배경, 논리적 사고 강함 | 요구 사항을 표현할 줄 아는 누구나 |

예를 들어, 날씨 조회 앱을 만든다고 해봅시다.

전통적인 프로그래밍 사고방식이라면:
1. 먼저 프로그래밍 언어(예: JavaScript)를 배움
2. 웹페이지 구축 방법을 배움
3. 날씨 API 호출 방법을 배움
4. JSON 데이터 처리 방법을 배움
5. 인터페이스 디자인 방법을 배움
6. 몇 주 동안 조금씩 코드를 작성함

Vibe Coding 사고방식이라면:
1. AI에게 말함: "도시 이름을 입력하면 온도와 날씨 상태를 보여주는 날씨 조회 웹페이지를 만들어 줘"
2. AI가 초안 코드를 생성함
3. 결과를 보고 말함: "검색 기록 기능도 추가해 줘"
4. AI가 추가해 줌
5. 말함: "인터페이스를 파란색 톤으로 바꿔서 더 산뜻하게 해줘"
6. AI가 조정해 줌
7. 30분 만에 완성!

![](https://pic.yupi.icu/1/codingway%25E5%25A4%25A7.jpeg)

차이점이 보이시나요? 전통적 프로그래밍은 "어떻게 할지"에 집중하고, Vibe Coding은 "무엇을 할지"에 집중합니다. **요구 사항을 명확히 말하는 것이 중요합니다.**



## 4. 실제 사례 하나

이론만 너무 많이 이야기했으니, 실제 Vibe Coding 사례를 보여드릴게요.


### 배경

제 친구 중에 선생님이 있는데, 매주 학생들의 출석, 과제 완성 현황을 학부모에게 보내야 했습니다. 예전에는 학생들의 상황을 일일이 문자로 편집했는데, 매번 한두 시간이 걸렸습니다.

그래서 저에게 학생 정보를 입력하면 자동으로 주간 보고 메시지를 생성해 주는 도구를 만들어 줄 수 있냐고 물었습니다.



### Vibe Coding으로 구현하기

저는 Cursor(주류 AI 코드 에디터 중 하나)를 열고 빈 디렉터리(생성된 프로젝트 코드를 담을 곳)로 들어간 다음, AI와 대화할 준비를 했습니다:

![](https://pic.yupi.icu/1/image-20260104123610886.png)

1라운드 대화:
```
나: 학생 주간 보고 생성기 웹페이지를 만들어 줘
요구 사항:
1. 학생 이름, 출석 일수, 과제 완성 수를 입력할 수 있어야 함
2. 생성 버튼을 클릭하면 주간 보고 텍스트가 자동 생성되어야 함
3. 클립보드에 원클릭 복사 가능해야 함
```

AI는 즉시 입력 폼과 버튼이 포함된 초안 페이지를 생성해 주었습니다.

![](https://pic.yupi.icu/1/image-20260104123951214.png)

2라운드 대화:
```
나: 주간 보고 형식을 이렇게 바꿔줘:
"【학생 주간 보고】{이름} 학생 이번 주 성취: 출석 {출석}일, 과제 {과제}개 완료. {평가}"
평가는 완성 상황에 따라 자동 생성해 줘
```

AI가 코드를 수정하여 스마트 평가 기능(엄청 똑똑하진 않지만)을 추가했습니다.

![](https://pic.yupi.icu/1/image-20260104124115828.png)

3라운드 대화:
```
나: 인터페이스가 너무 초라해. 산뜻한 초록색 톤으로 바꾸고, 둥근 모서리와 그림자 효과를 좀 넣어줘
```

AI가 인터페이스를 예쁘게 꾸며주었습니다.

![](https://pic.yupi.icu/1/image-20260104124230581.png)

4라운드 대화:
```
나: 이전에 생성한 주간 보고를 볼 수 있게 히스토리 기능을 추가해 줘
```

AI가 히스토리 기록을 추가했습니다.

![](https://pic.yupi.icu/1/image-20260104124459035.png)

시작부터 완성까지 총 **10분**도 걸리지 않았습니다. 제 친구는 지금 매주 이 도구를 사용하고 있고, 아낀 시간으로 저랑 마피아 게임 한 판 할 정도가 되었습니다.

이 과정에서 제가 무엇을 했는지 주목하세요:
- 저는 코드 한 줄도 작성하지 않았습니다 (전부 AI가 씀)
- 저는 단지 요구 사항을 명확히 표현했습니다
- 저는 여러 번의 대화를 통해 끊임없이 최적화했습니다
- 저는 구현 디테일이 아닌 기능과 효과에 집중했습니다

이것이 바로 Vibe Coding의 마법입니다!



## 5. Vibe Coding으로 무엇을 할 수 있나요?

Vibe Coding이 멋지게 들리긴 하는데, 도대체 이걸로 어떤 일들을 할 수 있을지 궁금하실 겁니다.

정답은: **여러분이 상상할 수 있는 거의 모든 소프트웨어 개발을 할 수 있습니다!**

예를 들어 다음과 같은 실용적인 소프트웨어들입니다:

1) 웹 애플리케이션: 개인 포트폴리오 사이트, 온라인 도구(할 일 목록, 가계부, 노트 등), 기업 공식 홈페이지, 블로그 시스템, 온라인 쇼핑몰

2) 미니 프로그램 / 앱

3) AI 애플리케이션: 챗봇, 지능형 글쓰기 도우미, 이미지 생성 도구, 음성 인식 앱

4) 데이터 처리 도구: 데이터 시각화, 자동화 리포트, 스프레드시트 처리 도구

5) 자동화 스크립트: 대량 파일 처리, 크롤러 도구, 자동화 테스트

6) 보조 도구: PPT 보여주는 웹페이지, 프로토타입 및 데모 사이트, 아키텍처 다이어그램 및 흐름도, 애니메이션 데모 사이트

Vibe Coding이 진화함에 따라 문제를 해결하는 우리의 사고방식도 더 넓어졌습니다. 저는 많은 업무를 "AI로 웹사이트를 생성해서 해결할 수 없을까?"라고 생각하게 되었습니다.

## 6. 왜 지금이 프로그래밍을 배우기 가장 좋은 시대인가요?

만약 프로그래밍을 포기한 적이 있다면, 좋은 소식을 알려드리겠습니다: **오늘은 인류 역사상 프로그래밍을 배우기 가장 쉬운 날입니다!**

**진입 장벽이 이렇게 낮았던 적은 없습니다**

예전에는 프로그래밍을 배우려면 적어도 몇 달은 기초 지식을 공부하고 수많은 에러와 디버깅을 마주해야 했습니다. 지금 Vibe Coding을 배우는 데는 사람 말만 할 줄 알고, 요구 사항을 표현할 줄 알면 됩니다. 며칠이면 시작할 수 있고, 대화하듯 프로그래밍하며 AI가 대부분의 문제를 해결해 줍니다.

**아이디어에서 제품까지의 거리가 더 짧아졌습니다**

예전에는 좋은 아이디어가 있어도 그것을 실현하려면 몇 달 동안 프로그래밍을 배우고, 다시 몇 주 혹은 몇 달을 개발에 쏟거나, 프로그래머를 고용해야 했고, 결국 아이디어를 포기하는 경우가 많았습니다.

이제 Vibe Coding을 사용하면, 오늘 떠오른 아이디어를 오늘 바로 만들 수 있고, 심지어 바로 배포하여 출시할 수 있으며, 비용은 거의 0에 가깝습니다.

**창의력이 기술보다 더 중요합니다**

AI 시대에 가장 중요한 것은 더 이상 "코드를 짤 줄 아는 것"이 아니라, 아이디어를 생각하는 것(창의력), 요구 사항을 표현하는 것(소통 능력), 반복 최적화하는 것(제품 사고력)입니다. 이런 능력은 누구나 기를 수 있습니다.

**평생 학습이 가능해졌습니다**

예전에는 프로그래밍 기술 업데이트가 너무 빨라서 배우고 나면 금방 구식이 되곤 했습니다. 이제는 AI 비서가 있어 새로운 기술이 나오면 AI가 이미 다 배웠기 때문에, 여러분은 AI에게 신기술로 구현해 달라고 말하기만 하면 됩니다. 에너지를 창의력과 제품에 집중할 수 있습니다.



## 7. Vibe Coding 3대 오해

Vibe Coding 학습을 시작하기 전에, 흔히 하는 3가지 오해를 풀어드려야겠습니다. 많은 분들이 이 오해 때문에 시작을 주저하곤 합니다.


### 오해 1. Vibe Coding은 속임수(Cheating) 아닌가요?

당연히 아닙니다!

일부 전통적인 프로그래머들은 "AI로 코드를 짜는 건 프로그래밍을 할 줄 모르는 거 아니냐?"라고 말할 수 있습니다.

그럼 한번 생각해 봅시다:
- 100년 전, 암산을 잘하는 사람은 계산기를 쓰는 것이 속임수라고 생각했습니다.
- 30년 전, 코드를 직접 쓰는 사람은 IDE(통합 개발 환경)를 쓰는 것이 속임수라고 생각했습니다.
- 오늘날, 코드를 직접 쓰는 사람은 AI를 쓰는 것이 속임수라고 생각합니다.

**도구의 발전은 속임수가 아니라 효율의 향상입니다.**

AI로 코드를 짜는 것은 디자이너가 포토샵을 쓰고 건축가가 CAD를 쓰는 것과 같은 정상적인 생산성 도구 활용입니다.

중요한 것은 어떻게 구현했느냐가 아니라, 무언가를 만들어 낼 수 있느냐, 문제를 해결할 수 있느냐입니다.



### 오해 2. Vibe Coding을 하면 학습 능력을 잃게 되나요?

어떤 분들은 걱정합니다. "항상 AI가 코드를 짜주면, 나는 아무것도 못 배우는 거 아닌가요?"

정반대입니다! Vibe Coding은 최고의 학습 방식입니다:
- AI가 코드를 생성한 후, 읽고 이해할 수 있습니다.
- 모르는 부분은 AI에게 설명을 요청할 수 있습니다.
- 코드를 수정해 보고 효과를 확인할 수 있습니다.
- 프로젝트를 하면서 동시에 학습할 수 있습니다.

저는 대학 시절 직접 프로젝트를 하면서 많은 신기술을 배웠는데, 이제 Vibe Coding이 있으면 처음에는 혼자 프로젝트를 할 능력이 없더라도 AI와 함께 몇 개의 프로젝트를 해보고 나면 신기술 코드를 이해할 수 있게 됩니다.

**실전에서 배우는 것이 책만 파는 것보다 효율이 훨씬 높습니다!**



### 오해 3: Vibe Coding은 간단한 장난감 프로젝트만 할 수 있나요?

당연히 아닙니다! 복잡한 프로젝트도 똑같이 할 수 있습니다!

어떤 사람들은 AI가 간단한 코드만 짤 수 있고, 복잡한 프로젝트는 여전히 프로그래머에게 의존해야 한다고 생각합니다.

하지만 실제로 오늘날의 AI는 이미 매우 강력합니다:
- 수만 줄의 코드가 있는 프로젝트를 처리할 수 있습니다.
- 복잡한 비즈니스 로직을 이해할 수 있습니다.
- 다양한 프레임워크와 기술 스택을 사용할 수 있습니다.
- 복잡한 버그 디버깅을 도와줄 수 있습니다.

인터넷에 떠도는 "AI로 상업용 수익화 프로젝트 독립 개발" 같은 거창한 이야기는 차치하고라도, YuPi 팀의 경우만 봐도 우리의 [프로그래밍 내비게이션 미니 프로그램](https://codefather.cn/)은 Vibe Coding으로 일주일 만에 개발 완료했습니다. YuPi도 전체 프론트엔드와 백엔드가 포함된 [《AI 프로그래머 기술 연병장》](https://bilibili.com/video/BV1dW4tz9E5M) 프로젝트를 AI로 개발하는 과정을 라이브로 보여드린 적이 있습니다.

![](https://pic.yupi.icu/1/1760439049424-532d6ad1-0600-4654-bd9b-311d48cfdc2f.png)

중요한 것은 AI의 능력이 아니라, 여러분의 요구 사항 표현 및 반복 능력입니다.



## 8. Vibe Coding의 문제점

Vibe Coding이 강력하긴 하지만, 솔직히 말씀드리면 현재 몇 가지 한계점도 존재합니다. 이 문제들을 이해하면 Vibe Coding을 더 이성적으로 사용하는 데 도움이 될 것입니다.



### 1. 인터페이스 동질화

AI로 생성한 많은 웹사이트 인터페이스가 비슷하게 생겼다는 것을 발견할 수 있습니다. 특히 색상이 옅은 보라색이나 청자색 그라데이션인 경우가 많습니다. 이는 AI의 훈련 데이터에 이런 디자인(혹은 인용된 스타일 코드)이 비교적 흔하기 때문에, AI가 유사한 스타일을 생성하려는 경향이 있기 때문입니다.

![](https://pic.yupi.icu/1/1752744100231-3dc376f3-7571-45c6-8f7c-6098ddde35cf.png)

독특한 디자인을 원한다면 프롬프트에 색상, 스타일, 참고 사례를 명확히 설명하거나, 디자인 시안을 제공하여 AI가 참고하게 해야 합니다.



### 코드 통제 불가 위험

더 골치 아픈 문제는 AI가 생성한 코드가 통제 불가능할 수 있다는 점입니다. AI는 현재 주로 소규모 프로젝트 생성에 사용되는데, 만약 규모가 좀 있는 코드베이스에서 AI를 사용하다 버그가 발생하면 디버깅이 어려운 **막다른 골목**에 다다를 가능성이 큽니다. AI가 생성한 코드를 이해하지도 못하고, 그렇다고 그 코드들을 포기하기도 아까운 상황이죠. 이전에 AI 커뮤니티에서 동료가 AI로 프로젝트를 망쳐놨다고 하소연하는 개발자를 본 적이 있습니다:

![](https://pic.yupi.icu/1/1752736716516-a86b3751-7c1f-42ad-b15a-b5721614f023.png)

그래서 제가 제안하는 것은:
- AI가 가능한 한 간단하고 명확한 코드를 생성하게 하세요.
- 매번 코드를 생성한 후에는 반드시 테스트하세요.
- 문제가 생기면 즉시 롤백하고, 한 길만 고집하지 마세요.
- 여건이 된다면 기초적인 프로그래밍 지식을 배우세요.



### 기술 퇴화 위험

장기간 Vibe Coding을 사용하면 기본적인 프로그래밍 기술을 잃을 수도 있습니다. 마치 계산기를 오래 쓰면 암산 능력이 떨어지는 것처럼요.

그래서 프로그래밍 기초가 있는 프로그래머 친구들에게 제안합니다:
- AI에 완전히 의존하지 말고, 어느 정도의 손코딩 능력을 유지하세요.
- AI가 생성한 코드를 맹목적으로 사용하지 말고 이해하려고 노력하세요.
- 주기적으로 AI 없이 연습하는 시간을 가지세요.
- AI를 대체품이 아닌 조수로 여기세요.

하지만 솔직히 말해서, 이 문제는 초보자 친구들에게는 전혀 문제가 되지 않습니다. 애초에 퇴화할 프로그래밍 기술이 없으니까요. 오히려 Vibe Coding 과정에서 많은 프로그래밍 지식을 배울 수 있습니다.



## 9. 학습 로드맵

이렇게 많이 이야기했으니, 벌써 학습을 시작하고 싶으실 겁니다. 그럼 어디서부터 시작해야 할까요?


### 완전 초보자 추천 경로

여러분을 위해 완벽한 학습 경로 지도를 준비했습니다:

![](https://pic.yupi.icu/1/vibecodingroadmap%E5%A4%A7.jpeg)

완전 초보자라면 이렇게 학습하는 것을 추천합니다. 시간 배분은 매우 여유롭게 잡았습니다.

1주차:
- 1일차: 이 글 읽기 (Vibe Coding 이해)
- 2일차: 빠른 시작 튜토리얼 완료 (첫 작품 만들기)
- 3-7일차: 노코드 플랫폼 학습

2-3주차:
- AI 코드 에디터 학습 (예: Cursor)
- 간단한 프로젝트 3-5개 만들기

1-2개월 차:
- 더 많은 도구를 선택적으로 학습
- 중급 난이도 프로젝트 만들기
- 심화 팁 학습

그 후:
- 지속적으로 프로젝트를 하며 경험 축적
- 필요에 따라 새로운 지식 학습
- 최신 도구 및 기술 주목



### 프로그래밍 기초가 있는 분

이전에 프로그래밍을 배웠거나 프로그래머라면, 이렇게 학습하세요:

1-2일차:
- 기초 내용 빠르게 훑기
- Vibe Coding 사고방식 이해
- 빠른 시작 튜토리얼 완료

1주차:
- 주류 AI 프로그래밍 도구 학습
- Vibe Coding으로 이전 프로젝트 리팩토링 시도
- 효율 향상 체감

그 후:
- 심화 팁 중점 학습
- 대화 및 컨텍스트 관리 능력 향상
- 워크플로 최적화 탐구



### 이 튜토리얼의 구조

학습을 더 쉽게 하기 위해 전체 튜토리얼을 몇 가지 섹션으로 나눴습니다:

1. 【기초 필독】: Vibe Coding 소개 + 빠른 시작 (필수 학습)
2. 【심화 선택】 프로그래밍 도구: 각종 AI 프로그래밍 도구 소개 및 선택 (필요에 따라 학습)
3. 【심화 선택】 프로젝트 실전: 10여 개의 완성된 프로젝트 사례 (하면서 배우기)
4. 【심화 선택】 경험 및 팁: 고수의 팁과 방법 (효율 향상)
5. 【심화 선택】 리소스 보물창고: 도구, 템플릿, 리소스 모음 (수시로 조회)

자신의 속도와 필요에 따라 선택적으로 학습할 수 있습니다.



### 학습 조언

마지막으로 몇 가지 학습 조언을 드립니다.

조언 1: 먼저 하고 나중에 배우세요
- 모든 이론을 먼저 배우려고 하지 말고 일단 손을 움직이세요.
- 빠른 시작 튜토리얼을 본 후, 즉시 프로젝트 하나를 만드세요.
- 실전에서 문제에 부딪히면 그때 돌아와서 배우세요.

조언 2: 프로젝트를 많이 하세요
- 프로젝트는 최고의 스승입니다.
- 간단한 프로젝트부터 시작해서 점차 난이도를 높이세요.
- 모든 프로젝트는 사용할 수 있고 보여줄 수 있게 만드세요.

조언 3: 시행착오를 두려워하지 마세요
- 틀리는 것을 두려워하지 마세요. AI가 고쳐줄 수 있습니다.
- 새로운 아이디어를 대담하게 시도하세요.
- 실패도 경험입니다.

조언 4: 경험을 기록하세요
- 매번 겪은 문제와 해결 방법을 기록하세요.
- 자신만의 프롬프트 템플릿을 쌓으세요.
