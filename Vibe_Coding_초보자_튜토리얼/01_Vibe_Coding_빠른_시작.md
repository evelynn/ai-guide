# 빠른 시작 Vibe Coding

> 10분 만에 첫 웹 애플리케이션 만들고 배포하기



안녕하세요, 프로그래머 YuPi입니다. 전 텐센트(Tencent) 풀스택 개발자이자 인터넷에서 200만 팔로워를 보유한 [AI 프로그래밍 인플루언서](https://space.bilibili.com/12890453)이며, [AI 내비게이션](https://ai.codefather.cn) 및 [프로그래밍 내비게이션](https://www.codefather.cn) 등 10개 이상의 자체 개발 제품을 만든 창작자입니다.

지난 글에서는 Vibe Coding의 이념과 사고방식에 대해 이야기했습니다. 이제 직접 실천해 볼 시간입니다!

이 글에서는 여러분이 10분 만에 첫 번째 웹 애플리케이션을 만들고, 인터넷에 배포하여 전 세계 사람들이 접속할 수 있게 하는 과정을 손수 이끌어 드리겠습니다.

네, 잘못 들으신 게 아닙니다. 프로그래밍 기초가 전혀 없어도 됩니다. 타자를 칠 줄 알고 인터넷을 할 줄 안다면 따라 할 수 있습니다.



## 1. 준비 작업

시작하기 전에 간단한 준비를 해야 합니다. 걱정 마세요. 아주 간단해서 5분이면 끝납니다.

준비물:

1. 인터넷이 되는 컴퓨터 (Windows, Mac 모두 가능)
2. 브라우저 (Chrome, Edge, Safari 모두 가능)
3. AI 도구 계정 (우리는 Bolt.new를 사용할 것입니다. 무료입니다)
4. GitHub 계정 (배포용, 역시 무료입니다)

이게 전부입니다. 어떤 프로그래밍 소프트웨어도 설치할 필요 없고, 코드를 배울 필요도 없습니다. 모든 것은 브라우저에서 이루어집니다.

💡 GitHub란 무엇인가요?

[GitHub](https://github.com/)는 현재 가장 주류인 무료 코드 오픈소스 호스팅 플랫폼으로, 코드를 저장하고 관리하는 "클라우드 드라이브"라고 이해하시면 됩니다. 모든 사용자나 팀은 자신의 코드를 GitHub에 업로드하여 공유하고 관리하거나, GitHub에서 코드를 다운로드할 수 있습니다. 개발자들은 GitHub에서 코드를 무료로 가져와 학습하거나 인용할 수 있습니다.

GitHub에 관심이 있다면 [YuPi의 친절한 GitHub 학습 로드맵](https://www.codefather.cn/course/1789189862986850306/section/1789190804671012866)을 무료로 학습해 보세요.



### AI 도구 선택 방법

완전 초보자에게는 Bolt.new로 시작하는 것을 강력히 추천합니다. 완전히 온라인 기반이라 소프트웨어 설치가 필요 없고 브라우저만 열면 됩니다. 그리고 가장 좋은 점은 코드를 작성하자마자 바로 효과를 볼 수 있고, 완성 후 원클릭으로 인터넷에 배포할 수 있어 진입 장벽이 전혀 없다는 것입니다. 초보자가 연습하기에 충분한 무료 사용량도 있습니다.

익숙해지면 나중에 Cursor 같은 전문 도구를 배워도 늦지 않습니다.

참고로, 네트워크 문제로 Bolt.new에 접속할 수 없다면 [Meituan NoCode(美团 NoCode)](https://nocode.cn/)나 [Baidu MiaoDa(百度秒哒)](https://www.miaoda.cn/) 같은 유사한 AI 애플리케이션 생성 플랫폼을 시도해 볼 수도 있습니다.



### Bolt.new 가입하기

1) 브라우저를 열고 주소창에 입력: https://bolt.new

2) 오른쪽 상단의 "Sign in" 버튼 클릭

3) Google 계정 / GitHub 계정 / 이메일 비밀번호 로그인 선택 (나중에 배포할 때 필요하므로 GitHub 계정 추천)

로그인에 성공하면 준비 작업은 끝났습니다. 이제 대화창에 요구 사항을 입력하여 프로젝트를 생성할 수 있습니다.

![](https://pic.yupi.icu/1/image-20260104140815455.png)



## 2. 첫 번째 프로젝트 선택하기

첫 번째 프로젝트는 매우 중요합니다. 여러분의 학습 경험을 직접적으로 결정하기 때문입니다. 저는 간단하지만 완성도 있고, 실제로 유용하며, 효과를 눈으로 볼 수 있는 프로젝트를 선택하는 것을 추천합니다.

제 경험상, 다음 프로젝트들이 초보자에게 적합하며 쉽게 완성할 수 있습니다.

1) 개인 명함 웹페이지: 이름, 프로필 사진, 자기소개, 연락처를 보여주는 깔끔하고 예쁜 페이지. 성취감을 빨리 느끼고 싶은 분께 추천.

2) 할 일 목록(Todo List) 앱: 간단한 작업 관리 도구로, 작업 추가, 완료 표시, 삭제가 가능. 실용적인 도구를 만들고 싶은 분께 추천.

3) 카운트다운 웹페이지: 목표 날짜(시험, 생일 등)를 설정하면 남은 일수를 실시간으로 보여주며 시각 효과가 예쁜 페이지. 창의적인 것을 만들고 싶은 분께 추천.

이 튜토리얼에서는 고전적인 **할 일 목록(Todo List) 앱**을 예로 들겠습니다. 기능이 완전하고 실용성이 강하며, 전체 개발 프로세스를 체험할 수 있기 때문입니다. 다른 프로젝트를 하고 싶어도 전혀 문제없습니다. 단계는 똑같고, 요구 사항 설명만 원하는 것으로 바꾸면 됩니다.



## 3. AI와 대화하여 코드 생성하기

자, 이제 가장 설레는 부분입니다. AI와 대화하며 코드를 생성해 봅시다.


### 1라운드 대화: 기본 요구 사항 설명

Bolt.new의 채팅창에 다음 내용을 입력하세요 (직접 복사해도 됩니다):

```
할 일 목록 애플리케이션 웹페이지를 만들어 줘. 요구 사항은 다음과 같아:

1. 기능 요구 사항:
   - 작업 내용을 입력하고 목록에 추가할 수 있어야 함
   - 각 작업 앞에 체크박스가 있어 클릭하면 완료 표시를 할 수 있어야 함
   - 완료된 작업은 취소선으로 표시
   - 각 작업 뒤에 삭제 버튼이 있어야 함
   - 완료된 작업 수와 미완료 작업 수를 표시

2. 인터페이스 요구 사항:
   - 깔끔하고 현대적인 디자인 스타일
   - 산뜻한 파란색 톤 사용
   - 둥근 모서리 버튼과 입력창
   - 적절한 그림자 효과
   - 반응형 디자인, 모바일에서도 정상 사용 가능

3. 기술 요구 사항:
   - HTML + CSS + JavaScript 사용
   - 데이터는 브라우저 로컬 스토리지(LocalStorage)에 저장하여 새로고침 해도 사라지지 않게 함
```

대형 모델 선택, 계획 모드 사용, 첨부 파일 추가, 프롬프트 강화 등을 선택할 수도 있지만, 처음에는 이런 것에 신경 쓰지 말고 그냥 전송 버튼을 누르고 AI의 응답을 기다리는 것을 추천합니다.

![](https://pic.yupi.icu/1/image-20260104141314370.png)




### AI는 무엇을 하고 있나요?

전송 후, Bolt.new가 작동하는 것을 볼 수 있습니다.

AI는 여러분의 요구 사항을 이해하고, 프로젝트 파일 구조를 생성한 다음, 자동으로 웹페이지 코드를 생성합니다. 전체 과정은 약 2분 정도 소요됩니다.

![](https://pic.yupi.icu/1/image-20260104141512389.png)

코드 생성이 완료되면 오른쪽에 미리보기 효과가 자동으로 표시됩니다. 입력창 하나, 추가 버튼 하나, 작업 목록 영역이 보일 것입니다.

입력창에 "YuPi와 Vibe Coding 배우기"라고 입력하고 추가 버튼을 클릭하여 효과를 확인해 보세요.

![](https://pic.yupi.icu/1/image-20260104141637255.png)




### 2라운드 대화: 디테일 최적화

초안 효과를 본 후, 디테일을 좀 수정하고 싶을 수 있습니다. 예를 들어:

```
아주 좋아! 하지만 몇 가지 조정하고 싶어:

1. 입력창의 플레이스홀더 문구를 "오늘 할 일은?"으로 바꿔줘
2. 추가 버튼을 "➕ 작업 추가"로 바꿔줘
3. 제목을 "나의 할 일 목록"으로 바꾸고 귀여운 아이콘을 추가해 줘
4. 배경색을 연한 파란색에서 연한 보라색으로 이어지는 그라데이션으로 바꿔줘
5. "완료된 항목 비우기" 버튼을 추가해 줘
```

시각적 수정 기능을 켜서 수정하고 싶은 요소를 선택하고, 마음에 안 드는 부분을 클릭할 수도 있습니다~

![](https://pic.yupi.icu/1/image-20260104141819294.png)

AI는 여러분의 요구에 따라 코드를 수정할 것이고, 곧 새로운 효과를 볼 수 있을 것입니다.

![](https://pic.yupi.icu/1/image-20260104142026165.png)




### 3라운드 대화: 새 기능 추가

더 많은 기능을 추가하고 싶다면 계속해서 AI와 대화하세요:

```
기능 몇 개만 더 추가해 줘:

1. 작업에 우선순위(상, 중, 하)를 설정할 수 있고, 색깔로 구분해 줘
2. 이미 추가된 작업을 편집할 수 있게 해줘
3. "전체 비우기" 버튼을 추가하고, 확인 팝업을 띄워줘
4. 작업 목록이 비어 있을 때 친절한 안내 문구를 보여줘
```

AI는 계속해서 이 기능들을 구현해 줄 것입니다.

![](https://pic.yupi.icu/1/image-20260104142238907.png)




### 대화 팁

AI와 대화할 때 다음 사항을 기억하세요:

1. 요구 사항은 구체적으로: "예쁘게 만들어 줘"라고 하지 말고 "배경을 파란색 그라데이션으로 바꾸고 버튼에 둥근 모서리를 넣어줘"라고 하세요.
2. 한 번에 너무 많이 고치지 말기: 매번 1~5개 정도의 요구 사항이면 충분합니다. 수정 후 효과를 보고 계속하세요.
3. 문제가 생기면 바로 말하기: 버그가 있거나 효과가 이상하면, 즉시 AI에게 "XX 부분에 문제가 있어"라고 말하세요.
4. 설명을 요청할 수 있음: 모르는 부분은 "이 코드는 무슨 역할을 해?"라고 물어볼 수 있습니다.



## 4. 효과 검증

자, 이제 할 일 목록 앱이 완성되었습니다. 각 기능을 테스트해 봅시다:

1) 입력창에 "YuPi와 Vibe Coding 배우기"를 입력하고 추가 버튼을 누르면 목록에 작업이 나타납니다.

2) 작업 앞의 체크박스를 클릭하면 작업 텍스트에 취소선이 그어지고, 삭제 버튼을 누르면 목록에서 사라집니다.

마지막으로 미리보기 창 상단의 기기 아이콘을 클릭하여 모바일이나 다른 화면 크기에서의 효과를 확인해 보세요.

![](https://pic.yupi.icu/1/image-20260104142538383.png)

만약 어떤 기능이 정상적으로 작동하지 않는다면 당황하지 마세요. 문제를 상세하게 AI에게 설명하세요. 예를 들어 "삭제 버튼을 눌렀는데 작업이 삭제되지 않아"라고 하면, AI가 버그를 수정해 줄 것이고 다시 테스트하면 됩니다.

이것이 Vibe Coding의 매력입니다. 문제가 생기면 AI가 해결해 줍니다!

## 6. 만든 것 이해하기

프로젝트를 마쳤으니, 몇 분만 투자해서 여러분이 만든 것을 이해해 봅시다. 나중에 더 좋은 프로젝트를 만드는 데 도움이 될 것입니다.




### 프로젝트 구조

먼저, 웹 애플리케이션의 기초는 "프론트엔드 3대장"임을 알아야 합니다:

- HTML(구조): 페이지에 어떤 요소(입력창, 버튼, 작업 목록, 통계 정보 등)가 있는지 정의합니다.
- CSS(스타일): 페이지가 어떻게 생겼는지(색상, 글꼴, 크기, 레이아웃 및 간격, 애니메이션 효과 등) 정의합니다.
- JavaScript(기능): 페이지가 어떻게 작동하는지(작업 추가, 완료 표시, 작업 삭제, 로컬 스토리지 로직 등) 정의합니다.

하지만 이 프로젝트에서 AI는 **React**라는 현대적인 프론트엔드 개발 프레임워크를 선택하여 기능을 구현했습니다. React는 현재 가장 인기 있는 프론트엔드 프레임워크 중 하나로, 개발을 더 효율적으로 만들고 코드를 유지 보수하기 쉽게 해줍니다.

그래서 프로젝트 파일에서 `.tsx` 확장자를 가진 파일들을 볼 수 있는데, 이것들이 바로 React 컴포넌트 파일입니다. 하지만 본질적으로 그것들은 최종적으로 브라우저가 이해할 수 있는 HTML, CSS, JavaScript로 변환됩니다.

![](https://pic.yupi.icu/1/image-20260104162356144.png)

괜찮습니다. 지금 이해하지 못해도 전혀 관계없습니다. 프론트엔드 개발에 관심이 있는 분이라면 [YuPi의 최신 친절한 프론트엔드 학습 로드맵](https://www.codefather.cn/course/1789189862986850306/section/1789190394078011393)을 통해 빠르게 입문할 수 있습니다.




### 핵심 기능 분석 (건너뛰기 가능)

몇 가지 핵심 기능이 어떻게 구현되었는지 살펴봅시다:

1) 작업 추가: "작업 추가" 버튼을 클릭하면, 프로그램은 먼저 입력창의 텍스트를 가져온 다음 새로운 작업 객체를 생성하고, 작업을 목록에 추가하는 동시에 로컬 스토리지에 저장하며, 마지막으로 입력창을 비우고 페이지 표시를 갱신합니다. 전체 과정은 마치 종이에 할 일을 적고 벽에 붙이는 것만큼 자연스럽습니다.

2) 완료 표시: 체크박스를 클릭하면, 프로그램은 해당 작업을 찾아 완료 상태를 수정하고, 로컬 스토리지를 업데이트한 다음, 페이지 표시를 갱신(작업 텍스트에 취소선 추가)하고 통계 숫자를 업데이트합니다. 마치 종이 위 작업에 펜으로 줄을 긋는 것과 같습니다.

3) 로컬 스토리지

페이지를 새로고침 했는데 왜 작업이 그대로 있는지 궁금할 수 있습니다.

이는 데이터가 브라우저의 로컬 스토리지(localStorage)에 저장되기 때문입니다. 작업을 수정할 때마다 프로그램은 최신 데이터를 localStorage에 저장하고, 페이지를 다시 열면 프로그램이 localStorage에서 이전에 저장된 데이터를 읽어옵니다. 따라서 브라우저를 닫아도 데이터가 손실되지 않습니다. 마치 잃어버리지 않을 작은 수첩에 할 일 목록을 적어둔 것과 같습니다.

![](https://pic.yupi.icu/1/theoryofworksoftware%E5%A4%A7.jpeg)



### AI에게 물어보기

만약 특정 부분을 깊이 이해하고 싶다면, AI에게 직접 물어보세요:

```
로컬 스토리지는 어떻게 작동하는지 설명해 줄래?
```

또는:

```
이 코드는 무슨 역할을 해?
[코드 붙여넣기]
```

AI가 알기 쉬운 말로 설명해 줄 것입니다.



## 7. 수정 및 최적화 시도하기

이제 실용적인 작은 소프트웨어를 가졌으니, 몇 가지 수정과 최적화를 시도하며 이해를 깊게 해봅시다.

다음과 같은 것들을 시도해 보세요:

- 색상 테마 변경 ("앱을 핑크색 테마로 바꿔줘, 부드럽고 귀여운 느낌으로")
- 텍스트 수정 ("모든 텍스트를 영어 버전으로 바꿔줘")
- 레이아웃 조정 ("통계 정보를 페이지 하단으로 옮기고 가운데 정렬해 줘")

또는 새로운 기능을 추가해 보세요:

- 작업 검색 ("검색창을 추가해서 작업 내용을 검색할 수 있게 해줘")
- 작업 분류 ("분류 기능을 추가해서 작업에 태그를 달 수 있게 해줘")
- 내보내기 기능 ("버튼을 추가해서 모든 작업을 텍스트 파일로 내보낼 수 있게 해줘")

사용자 경험을 최적화하여 앱을 더 쓰기 편하게 만들 수도 있습니다:

- 단축키 추가 ("엔터 키를 누르면 작업을 빠르게 추가할 수 있게 해줘")
- 애니메이션 추가 ("작업 추가 시 페이드인 효과, 삭제 시 슬라이드 아웃 효과를 넣어줘")
- 빈 상태 최적화 ("작업이 없을 때 귀여운 일러스트와 격려 문구를 보여줘")

만약 간단하다고 느껴진다면, 다음을 시도해 보세요:

- 마감 기한 기능
- 작업 알림 기능
- 드래그 앤 드롭 정렬 지원
- 다크 모드 전환 추가
- 여러 개의 작업 목록 지원

새로운 기능을 추가하고 싶을 때마다 AI에게 "나는 [기능 설명]을 추가하고 싶은데, 어떻게 해야 해?"라고 말하면 AI가 구현을 도와줄 것입니다.

이 프로젝트를 통해 여러분은 AI에게 요구 사항을 명확히 설명하는 법, 여러 번의 대화를 통해 프로젝트를 최적화하는 법, 문제가 생겼을 때 AI와 협력하여 해결하는 법, 그리고 프로젝트를 인터넷에 배포하는 법을 배웠습니다. 코드를 직접 쓰지는 않았지만, 웹 애플리케이션의 기본 구조, 사용자 상호작용 구현 방식, 데이터 저장의 기본 개념을 이해했습니다.

더 중요한 것은 Vibe Coding의 사고방식을 확립했다는 것입니다: **"어떻게"보다 "무엇"에 집중하고**, 먼저 만들고 끊임없이 최적화하며, 배우고 나서 하는 것이 아니라 하면서 배우고, AI를 도구가 아닌 프로그래밍 파트너로 여기는 것입니다.

이것은 시작일 뿐입니다. 더 많은 프로젝트를 할수록 요구 사항 표현 능력은 강해지고, 기술에 대한 이해는 깊어지며, 만들 수 있는 것은 더 복잡해지고, 창의력은 진정으로 해방될 것입니다.

제가 첫 번째 글에서 했던 말을 기억하세요: **AI 시대에는 창의력이 기술보다 중요하고, 아이디어가 구현보다 중요하며, 반복 개선이 완벽함보다 중요합니다.**
